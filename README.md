# NEBULA — Duelo espacial

Jogo de combate espacial em tempo real feito em Java com Swing.

## Requisitos

- JDK 26 ou superior
- Maven instalado

## Como executar

No terminal, na pasta do projeto, compile e inicie o jogo:

```bash
mvn compile
java -cp target/classes org.example.Main
```

Também é possível abrir o projeto no IntelliJ IDEA e executar a classe `org.example.Main`.

## Controles

- **WASD** ou **setas**: mover a nave
- **Espaço**: disparar
- **Enter**: jogar novamente após o fim da partida
